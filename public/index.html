Manifest

Sembilan endpoint, tiga lapis akses

Endpoint publik untuk daftar & masuk, endpoint JWT untuk kelola API key, dan endpoint berbayar-data yang dijaga API key sendiri.

MethodPathKeteranganAkses
POST /auth/register Daftar akun baru, menerima token JWT publik
POST /auth/login Masuk dengan email & password publik
POST /api-keys Terbitkan API key baru JWT
GET /api-keys Daftar API key milik akun JWT
GET /api-keys/usage Statistik pemakaian 24 jam terakhir JWT
DELETE /api-keys/:id Cabut (revoke) API key JWT
GET /v1/regions Daftar wilayah — filter provinsi/tipe/pulau, pagination API key
GET /v1/regions/:code Detail satu wilayah berdasar kode API key
GET /v1/regions/stats Agregat populasi, luas, densitas per provinsi API key

Rute Akses

Tiga pemberhentian dari akun kosong ke data pertama

Alur yang sama dipakai di dokumentasi teknis (ERD, use case, activity diagram) proyek ini.

1

Daftar & masuk

Kirim nama, email, dan password. Sistem membalas token JWT untuk sesi Anda.

POST /auth/register
2

Terbitkan API key

Pakai token JWT untuk membuat API key — inilah yang dipasang di aplikasi Anda.

POST /api-keys Authorization: Bearer <jwt>
3

Ambil data

Panggil endpoint data dengan header x-api-key. Tidak perlu JWT lagi di titik ini.

GET /v1/regions x-api-key: <key>

Contoh Nyata

Satu request, satu balasan

Contoh memanggil data wilayah dengan filter provinsi.

request.sh
curl "https://indoregion-api.vercel.app/v1/regions?province=Bali" \
  -H "x-api-key: irk_xxx...xxx"
